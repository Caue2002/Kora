# frontend/

Interface responsiva mobile-first contendo apenas o chat com o agente Nori.

- Tela exclusiva de chat com campo de envio fixo no rodape
- Controle de sessao na aba via sessionStorage
- Envio de mensagens e acoes rapidas de resposta (copiar, exportar, avaliar)
- Paleta: fundo #F8FAFC, usuario #065F46, agente #FFFFFF/#E2E8F0, acentos #047857
